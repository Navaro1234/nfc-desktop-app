# Email Addon

NFC Master addon for preparing an email from NFC data.

## Features
- Open the default mail client with a pre-filled recipient, subject and body.
- Uses the NFC payload as the message body when no custom body is configured.
- No email password or SMTP credentials are stored in the addon.

The addon package is built from this source folder into `EmailAddon.ndnfcaddon` by the repository addon build workflow.

Build trigger: Email Addon 1.0.0
